# Carpeta de Banners Publicitarios — Elijo Tecnología

Coloca aquí los archivos de imagen para los banners publicitarios de la tienda.

### Especificaciones recomendadas:
- **Dimensiones:** 1920 × 600 px (Relación aproximada 3.2:1)
- **Formatos:** WebP (recomendado por rendimiento) o JPG / PNG.
- **Nombres de ejemplo:**
  - `banner-01.webp`
  - `banner-02.webp`
  - `banner-03.webp`

El sistema cargará automáticamente las imágenes existentes en esta carpeta según la configuración en `banner-config.js`.
